# PWA / Installierbar — Implementation Plan

**Goal:** App auf dem Homescreen installierbar. Service Worker + Manifest.

## Task 1: Manifest

### public/manifest.json
```json
{
  "name": "Anime Tracker",
  "short_name": "AnimeTracker",
  "description": "Gemeinsame Anime-Sammlung von Chrischi & Michelle",
  "start_url": "/anime-tracker/",
  "display": "standalone",
  "background_color": "#0F0F23",
  "theme_color": "#7C3AED",
  "icons": [
    { "src": "/anime-tracker/icons/icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/anime-tracker/icons/icon-512.png", "sizes": "512x512", "type": "image/png" }
  ]
}
```

### public/icons/
- icon-192.png und icon-512.png generieren (einfarbiges SVG, in PNG konvertiert)

## Task 2: Service Worker

### public/sw.js
Minimaler Service Worker mit Cache-First für statische Assets:
```javascript
const CACHE = 'anime-tracker-v1';
self.addEventListener('install', e => e.waitUntil(
  caches.open(CACHE).then(c => c.addAll(['/anime-tracker/', '/anime-tracker/index.html']))
));
self.addEventListener('fetch', e => e.respondWith(
  caches.match(e.request).then(r => r || fetch(e.request))
));
```

## Task 3: BaseLayout.astro

```html
<link rel="manifest" href="/anime-tracker/manifest.json" />
<meta name="theme-color" content="#7C3AED" />
<script>
  if ('serviceWorker' in navigator) {
    navigator.serviceWorker.register('/anime-tracker/sw.js');
  }
</script>
```

npm run build

ls dist/manifest.json dist/sw.js
